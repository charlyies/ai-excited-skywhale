A colossal luminous whale bursts out of a huge gilt-framed oil painting in a
grand museum hall. The painted stormy ocean spills from the frame as real
water cascading onto the marble floor, tiny museum visitors flee in awe, and
a glowing miniature coastal city with a lighthouse shines on the whale's back
while god rays stream through tall arched windows.

## How it works

The entry image (`entry.png`, 1024×1024 JPEG) was generated for this
competition. `main.ts` is a small Node 22 stdlib-only program that copies
`entry.png` into the make.fun output directory (`$MAKEFUN_OUTPUT_DIR`,
falling back to `/output`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.png
```
