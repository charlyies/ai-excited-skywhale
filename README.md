# Skywhale — ai-excited-01

A colossal luminous whale bursts out of its gilt-framed painting in a museum gallery. Water floods the marble floor, visitors flee, and a tiny glowing city with a lighthouse rides on the whale's back — the painting come alive.

The program (`main.ts`) simply copies the finished image `entry.png` to the output directory, byte for byte.
