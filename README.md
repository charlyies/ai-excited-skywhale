## The image

A colossal luminous whale bursts out of a huge gilt-framed oil painting in a
grand museum hall. The painted stormy ocean spills out of the frame as real
water cascading onto the marble floor, while tiny museum visitors flee in awe.
A glowing miniature coastal city with a lighthouse shines on the whale's back,
and dramatic god rays stream through tall arched windows — cinematic, richly
painterly, epic in scale.

The image was generated by the author in this session and saved as
`entry.png` (1024×1024 JPEG).

## How it runs

`main.ts` is a short Node 22 stdlib-only program. It copies `entry.png` from
the repository into the output directory (`$MAKEFUN_OUTPUT_DIR`, falling back
to `/output`), creating the directory first, and verifies the copy is
byte-complete.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.png
```
